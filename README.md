# Meng Health (梦健康) 🥑

一款专为个人自律减脂打造的轻量级饮食与热量记录 APP。
界面 1:1 还原极简健康美学设计，内置动态热量预算环、三大营养素进度、AI 智能速记卡片、四餐打卡卡片，以及 iOS 16 风格的悬浮毛玻璃底栏。

---

## ✨ 核心特性

- 🎯 **热量预算仪表环**：动态计算今日剩余可吃千卡，清楚掌握热量缺口。
- 🥗 **三大营养素追踪**：蛋白质、碳水化合物、脂肪专属三色进度条。
- ✨ **AI 智能拍照速记**：支持直接拍照、相册选图或文本描述，智能估算食物克数与热量营养素；预留大模型 API 接口，随时一键接入。
- 📱 **iOS 16 悬浮毛玻璃底栏**：半透明高斯模糊质感（Glassmorphism），空间层次感拉满。
- 💾 **数据备份与换机迁移**：纯本地离线隐私存储，提供“一键导出备份（JSON）”和“一键恢复导入”，换手机数据零丢失。
- 🇨🇳 **纯正全中文交互**：从界面文字、指标单位到食物库全部采用简体中文，无多余外语与广告骚扰。

## 📲 安装包下载使用

在项目的 [GitHub Releases 页面](https://github.com/Own716/Meng-Health/releases) 中，直接下载最新的 **`Meng-Health-v1.0.0.apk`** 文件，微信/QQ 发送到安卓手机或直接在手机浏览器中下载安装即可使用！

## 💻 本地运行与开发

```bash
# 1. 安装项目依赖
npm install

# 2. 启动本地开发服务 (带热更新)
npm run dev

# 3. 生产环境构建
npm run build
```

---

## 🔑 AI 接口配置指南

1. 进入 APP 右上角「个人中心」或底栏「我的」-> 打开「数据备份与换机中心」。
2. 展开底部的「AI 接口与 API Key 配置」。
3. 填入您的 API Key（如 Google Gemini API 或代理服务），点击保存即可直接激活真实的视觉识图功能！
